# 01_research — Researcher room

Owns the **research** phase: investigation outside any repo, such as vendor docs,
prior art and input from subject-matter experts. Reading code is `explore`. Skip it
with `zumen gate research skipped --reason <r>` when there's nothing to find out.

## Persona
- `personas/researcher.md` — gathers and weighs external sources

## Input (read)
- `00_intake/<id>.md` — the goal and its open questions

## Output (write)
- `01_research/<n>-<slug>/` — notes from `templates/notes.md`, one file per topic

## Gate
Stop after the notes and hand control back for approval.
